# sb-trading-preview
SB Trading — Materials in Motion | client review draft (non-production, `noindex`).

- `index.html`, `styles.css`, `site.js`: one continuous blue-hour scroll story in five stages (Arrive → Discover → Transition → Explore → Enquire), with a chapter bar along the bottom.
- `assets/film/{d,m}/`: 142 WebP frames scrubbed by scroll (desktop 1280×720, phone 405×720 crop), built by `tools/build-film.py` from the owner's showroom reference clip (`gemini_generated_video_97f87dc2`, generated footage): the dark bamboo grove and the light at its end (0-1.95 s), the fibre close-ups (3.0-5.95 s, zoomed and edge-softened so its drifting cards with invented text are illegible) and the gallery of three labelled cases (6.0-7.4 s). Left out: its showroom close-up (plinth cards misspell the company name) and its drawn-in quote form. Labelled on the page as generated, not SB Trading's own. No stock footage. The Gemini clip `9f29a4ec` stays out (owner's instruction). `docs/storyboard.html` sets the reference videos beside the site scene by scene; `docs/wireframes.html` is the measured layout.
- Explore stage: one pinned stage, three families. Each family's real photographs sit in an arched window that wipes in and tilts in 3D with the pointer; the blurred photo fills the background.
- `assets/photodepth.js` + `assets/img/depth/`: photographs in depth. Each family's real photo is drawn in raw WebGL2 with a depth map (Depth Anything V2 Small, generated offline from the same photo): scroll dolly, pointer parallax, depth of field, distance haze, a light sweep. Every pixel is SB Trading's photo; nothing modelled. Draws only during input, then stops. No WebGL2, reduced motion or context loss: the plain photo.
- `assets/rifat.js` + `src/rifat-fn.js` → `functions/api/rifat.js`: Rifat, the enquiry assistant. With the Cloudflare Pages variable `ANTHROPIC_API_KEY` set, the Pages Function answers with Claude and records enquiry fields; without it (or on a local server) Rifat runs as a labelled guided enquiry. The finished enquiry opens WhatsApp to SB Trading's number (+880 1878-707910, set in `data-whatsapp` on `<body>`) with the text filled in; it can also be copied.
- `assets/sound.js`: opt-in tactile sound, loaded only when the visitor presses Sound. Synthesised cues, no background bed: a hollow bamboo knock per family, a fibre brush on product hover, a soft chime when Rifat replies, a pluck when a message is sent.
- `assets/img/`: real product photographs; `sb-logo*.webp` and `sb-mark*.webp` are the original SB Trading logo with its white background removed (`-light` = the same mark knocked out to Cloud White for dark grounds; derived from the owner's file, awaiting approval).
- `assets/vendor/`: Motion 12, Lenis (bundled) and self-hosted fonts (Gloock, Schibsted Grotesk; OFL). No external requests from the page.
- Opening: the film itself, as in the owner's reference: darkness, then light shafts between bamboo with seeded gold dust drifting in them, the title, 3 families · 9 products · Bangladesh, Explore / Ask Rifat, and a scroll ring that fills as the film begins. Scrolling walks forward through the grove into the light, through the fibres, and ends in the gallery of three lit cases; each caption has its own soft scrim so the footage keeps its light. Reduced motion shows a poster without the dust. Products open a spec drawer: a pane of white frosted glass with a brand-blue main button floating over the stage (right side on desktop, from the bottom on phones) with the photograph, a spec list (family, grade for graded yarns, supplied from Bangladesh; specification and minimum order "confirmed in your quotation" until SB Trading confirms them), "Request a quote" (the enquiry form opens in the drawer beside the product, then Send on WhatsApp there; it is the same form as Contact Us's), "Add to enquiry", "Ask Rifat about it" and the WhatsApp hand-off line. Explore is a bright showroom that stays inside the film's last room (the reference's gallery, softly out of focus behind each family): warm white walls, ink text, brand-blue accents, dimming to dusk as it leaves, with the header and chapter bar turning ink over it. In Explore each family's arch stands on a numbered plinth (01 / 03) with arrows to the families either side; added products collect in an enquiry tray that opens Rifat.
- The plain quotation form (under "Prefer a form?") works without Rifat and without JavaScript submission; it fills the same enquiry.
- `v1/`: the first single-file draft, kept unchanged.
- `DESIGN.md` (v1.0.0) + `.impeccable/design.json`: the design system recorded from the shipped code (28 semantic tokens, components and states, motion, type). `tests/tokens.mjs` fails the build if `styles.css :root` and DESIGN.md disagree.
- `docs/user-journey.md`: buyer journey (current vs desired) and gap analysis; assumptions until tested with real buyers.
- Build and test: `npm ci`, `npm run build`, `npx playwright install chromium`, `npm test` (166 checks: design tokens, copy and navigation, film sync, Rifat AI against a simulated API, the score rendered offline, caption contrast, accessibility with axe-core, and browser smoke on desktop and phone, including the film label and the dust, the spec drawer, the quote form in the drawer, the exhibit plinths and the lit showroom). Set `CHROMIUM_PATH` where Playwright cannot install its own browser. GitHub Actions runs the same on pull requests and pushes to `main`; it does not deploy.
- Operational notes, open items and the Access decision gate: `HANDOFF_CODEX.md`.
- Not used from the AI drafts: invented specifications, certifications and pricing. Add them only after SB Trading confirms.
- `video/`: the Remotion brand film (16 s with sound, 16:9 and 9:16), built from the site's design system, photographs, depth renderer and score. `cd video && npm install && npx playwright install chromium && npm run render`. Rendering syncs colours and assets from the site (`sync-design.mjs`) and renders the soundtrack (`render-score.mjs`, needs Playwright's Chromium and ffmpeg). In a sandbox without downloads, set `CHROMIUM_PATH` (and `REMOTION_BROWSER` for Remotion's headless shell) to installed browsers instead. `tests/film-sync.mjs` fails if the film drifts from DESIGN.md or the site's copy.
